## AI-Native Engineering

I treat AI tools as force multipliers across the whole development cycle — from design and implementation to review and operations — while keeping ownership of architecture, correctness, and security.

| Tool | How I use it |
|---|---|
| **Claude Code** | Agentic coding in the terminal: exploring large codebases, multi-file refactors, implementing features end to end, writing tests, debugging, and automating repetitive tasks with custom instructions, skills, and subagents. |
| **OpenAI Codex** | Delegating well-scoped tasks (bug fixes, boilerplate, test generation) and comparing approaches against other tools. |
| **GitHub Copilot** | Inline completion and chat inside the IDE for day-to-day coding, boilerplate, and quick explanations. |
| **Antigravity** | Agent-first development: planning and running multi-step tasks across editor, terminal, and browser. |

**How I work with AI tools**

- **Context engineering** — writing clear specs, project instructions, and constraints so the agent produces code that fits the codebase.
- **Task decomposition** — breaking work into small, verifiable steps and choosing the right tool for each one.
- **Review-first mindset** — I read, test, and own every change an agent produces; AI speeds up delivery, it doesn't replace judgment.
- **Automation** — building internal AI agents with RAG and LLM integration, plus pipelines that keep their knowledge up to date.
- **Tool fluency** — comfortable switching between CLI agents, IDE assistants, and agent-first IDEs depending on the task.
